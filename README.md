# blankcut CLI releases

Release binaries for [Blank Cut](https://blankcut.com)'s command-line tool, `blankcut`. The source
is not published here; this repository only holds signed release artifacts.

**Not published yet.** Each release will carry archives for macOS, Linux and Windows, a
`checksums.txt`, and a signature for that checksum file. Verify an archive against `checksums.txt`
before running it.

The CLI needs a Blank Cut account — sign up at [meerkat.blankcut.com](https://meerkat.blankcut.com),
or run `blankcut login`, which walks you through it.
